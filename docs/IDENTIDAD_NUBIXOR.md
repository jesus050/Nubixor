# Identidad visual de Nubixor

## Concepto del símbolo

El símbolo combina cuatro ideas del producto:

- **Nube:** operación y datos disponibles desde una plataforma central.
- **Gráfica ascendente:** crecimiento, lectura financiera y toma de decisiones.
- **Barras:** indicadores, inventario, ventas y control empresarial.
- **Flecha:** avance, automatización y mejora continua.

El cuadrado de esquinas amplias funciona como ícono de aplicación y mantiene
una presencia amable frente al carácter técnico de un ERP.

## Paleta extraída

| Uso | Color |
| --- | --- |
| Azul noche / texto principal | `#071D59` |
| Cian tecnológico | `#00BAF2` |
| Azul de transición | `#2474F2` |
| Violeta | `#7746F2` |
| Púrpura | `#AA30EE` |
| Magenta | `#EE2BB2` |
| Coral | `#FF5E6E` |
| Naranja de crecimiento | `#FF981D` |
| Fondo operativo | `#F6F8FF` |

El azul noche debe dominar navegación, texto y superficies de control. El
espectro se reserva para marca, acciones principales, progreso y destacados.
El naranja no debe usarse como color general de botones porque puede confundirse
con advertencias.

## Tipografía

- **Marca:** construcción redondeada, geométrica y amigable.
- **Interfaz:** `Avenir Next` o una sans legible equivalente.
- **Títulos editoriales:** la familia condensada vigente en Nubixor se conserva
  para mantener jerarquía y aprovechar el espacio del dashboard.
- **Importes y tablas:** números tabulares para facilitar comparaciones.

## Aplicación

- Favicon e ícono para dispositivos.
- Pantalla de acceso y verificación de sesión.
- Barra lateral.
- Terminal de caja.
- Comprobantes impresos.
- Acciones principales, acentos del dashboard y estados destacados.

## Reglas de uso

- No deformar, inclinar ni recolorear el símbolo.
- Mantener espacio libre alrededor del ícono.
- Usar la versión horizontal sobre fondos claros.
- Sobre fondos oscuros, usar el ícono junto al nombre en blanco.
- No usar el espectro completo como fondo de tablas o áreas extensas.
- La identidad de la empresa usuaria y su logo en facturas siguen siendo
  independientes de la marca de plataforma Nubixor.
